# Computação distribuída

## Trabalho 1

Cálculo analítico da disponibilidade de um serviço replicado, considerando servidores independentes. O programa apresenta uma tabela e gráficos para comparar os casos k = 1, k = n/2 e k = n.

### Executar

```bash
cd "trabalho 1"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```
